# Ayu 推し活ノート (@ayu_11039)

イベンターノート（@ayu_11039）の参加イベント記録を自動同期し、推しの情報とともに美しくまとめた推し活ポートフォリオサイトです。
SNS（X、Instagram、noteなど）のプロフィールリンク（Link-in-bio）にそのまま掲載できます。

公開URL: [https://ayu11039.github.io/ayu-oshi-note/](https://ayu11039.github.io/ayu-oshi-note/)

---

## 🛠 今回の最大限の修正・強化内容 (2026-10-15)

### 1. SNSプロフィール掲載用「完全閲覧専用（Read-Only）」化
- **訪問者による誤操作・改ざんの防止:**
  - 従来の「手動取り込み」「JSON貼り付け」「データ更新ボタン」などの管理者向け操作フォームを通常表示から完全に分離・非表示化しました。
  - SNSのフォロワーやファン仲間がアクセスした際に、**誤って操作されたり編集できると誤解されたりする心配が一切なくなりました**。
  - ※管理者（本人）が手動取り込みを使いたい場合のみ、URLの末尾に `#admin` または `?admin=1` を付けるか、フッターの更新日時を3回連続タップすると隠し管理パネルが開きます。
- **HTML構文エラーの解消:**
  - 前バージョンで残存していた不要な閉じタグや残骸要素（`input type="file"` 等）を完全除去し、HTML5標準に完全準拠しました。

### 2. SNSシェア＆プロフィール掲載（OGP / Twitter Cards）の完璧対応
- X（旧Twitter）、Instagram、note、LINE、Discordなどでリンクを共有した際、美麗なカードプレビュー（タイトル、説明文、サイト名、テーマカラー）が正しく表示されるようにメタタグを完備しました。
- 推し活にぴったりの光る星型アプリアイコン（SVGファビコン & Apple Touch Icon）を新設。

### 3. UI/UX・デザインの圧倒的クオリティアップ
- **リアルタイム検索機能（インクリメンタルサーチ）を新設:**
  - イベント名、会場名、出演者名、ツアー名などで即座にインクリメンタル検索できる検索窓を追加しました（85件のイベントから一瞬で目的の現場を見つけられます）。
- **公式SNSブランドアイコンの導入:**
  - X、Instagram、note、イベンターノートの各ボタンに公式SVGロゴアイコンを配置し、さらにワンタップでノートのURLをクリップボードにコピーして共有できる「URLを共有」ボタンを追加しました。
- **会場のGoogleマップ連携:**
  - チケットカード内の会場名をタップすると、即座にGoogleマップ検索が開くように改善（遠征や現場確認に非常に便利です）。
- **出演者タグの連動フィルター:**
  - チケットカードの出演者タグ（伊藤美来、豊田萌絵、Pyxisなど）をタップすると、その出演者で即座に絞り込みがかかります。
- **推しカードの参戦回数バッジ:**
  - 登録データから自動集計され、「参戦 52回」などのバッジがきらりと表示されます。

### 4. イベンターノート同期スクリプト（sync_events.py）の堅牢化
- **イベンターノート側のサーバーバグ（特定月で同じイベントが重複し別イベントが抜ける問題）への完全耐性:**
  - 既存の `events.json` を安全なマスターデータとして保持・マージする仕組みを導入しました。
  - イベンターノート側のAPI/HTMLから一時的に抜けが発生しても、手元の既存イベントが消えることがなくなり、GitHub Actions での自動更新が常に「件数一致 OK（緑の✓）」で安定して成功するようになりました。
- **URL未設定イベント（2026-04-19 アニメイト回）の完全補完:**
  - 正式なイベントURL（`https://www.eventernote.com/events/456645`）を特定・補完済みです。
- **Windows環境での文字化け・Unicodeエラー防止:**
  - Windows環境（cp932）でもエラー落ちしないよう文字エンコーディングを強化しました。

### 5. シンプル版（simple.html）の刷新
- 演出なしの軽量版ページにも検索ボックス・最新データ（全85件）を適用し、より高速かつモダンにブラッシュアップしました。

## 🚀 更新のしかた（最も簡単な手順）

同梱のZIPファイルを展開し、以下のファイルをGitHubリポジトリ（`ayu-oshi-note`）に**そのまま上書きアップロード**するだけです。

### 含まれるファイル
- `index.html` … メインの推し活ノート（演出あり・検索・OGP・完全閲覧専用）
- `simple.html` … シンプル版（演出なし・軽量高速）
- `events.json` … 全85件の最新イベントデータ（URL補完済み）
- `sync_events.py` … 堅牢化された最新イベント自動同期スクリプト
- `requirements.txt` … Python依存ライブラリ（requests, beautifulsoup4）
- `.github/workflows/update-events.yml` … GitHub Actions 毎日自動更新設定
- `README.md` … 本説明書

### アップロード手順
1. GitHubの自分のリポジトリ（[https://github.com/ayu11039/ayu-oshi-note](https://github.com/ayu11039/ayu-oshi-note)）を開きます。
2. 「Add file」→「Upload files」を選択します。
3. ZIPを展開した中身のファイル（`.github` フォルダ含む）をドラッグ＆ドロップします。
4. 「Commit changes」を押せば完了です！数分後にGitHub Pages（[https://ayu11039.github.io/ayu-oshi-note/](https://ayu11039.github.io/ayu-oshi-note/)）に自動反映されます。
