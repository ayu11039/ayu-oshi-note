# Ayu 推し活ノート

イベンターノート @ayu_11039 の参加イベントをすべて表示する、推し活サイトです。

## 今回の修正(2026-10-13)
**症状:** 同期は成功(緑✓・「件数一致 ✓」)なのに、登録しているイベントがサイトに入らない/日によって変わる。

**原因:** イベンターノートの「参加イベント一覧」をページ送り(1→2→3ページ)で読むと、
**同じイベントが2回出て、別のイベントが抜ける**ことが日によって起きていました(1ページにつき1件ほど)。
行の数は85のまま変わらないので、旧版の「85件と一致したら保存」では見抜けず、
重複を含んだまま「一致 ✓」で保存されていました。(実際の `events.json` は 85行・中身は82件でした)

**直したこと:**
- `sync_events.py` … 月ごとのページ(カレンダーの月リンク)から読み、同じイベントページ(URL)は1件にまとめ、
  **重複を除いた件数**が「参加イベント一覧(N件)」と一致したときだけ保存します。
  足りないときは、足りない月・年ごと・全期間と方法を変えて読み直し、集めたものを合体します。
  それでも揃わなければ、`events.json` は書き換えずに赤い×で止まります。
- `index.html` … 同じURLの行は表示でも1件にまとめます。内蔵データ(フォールバック)も85件(重複なし)に更新しました。背景と文字の見やすさも直しました(下記)。
- `events.json` … 抜けていた3件を補った85件にしてあります(次の同期で自動的に置き換わります)。

## イベントが表示されない問題の修正(いちばんの原因)
- **原因:** スクロールで文字が「透明→表示」になる演出が壊れていて、通常の設定のブラウザでは、
  「参戦イベント」の見出し・件数・絞り込み・**イベント一覧が透明のまま**になっていました。
  (データは読み込めていて、画面上で見えなくなっていただけです。最初のファイルからあった不具合です)
- **直したこと:** この演出をやめて、文字とイベント一覧は最初から必ず見える状態にしました。
  
  また、85枚のチケットすべてにかけていた「ぼかし」も外しました(スマホで重くなる・表示が崩れることがあるため)。
- **`simple.html`(新規):** 演出を一切使わない「シンプル版」のページです。
  メインのページ下の「シンプル表示(演出なし)」からも開けます。イベントが見えない時の保険になります。

## 更新のしかた(いちばん簡単な手順)
1. ZIPを展開すると `ayu_oshi_note` フォルダーができます。中の5つのファイル
   (`sync_events.py` / `index.html` / `simple.html` / `events.json` / `README.md`)を、GitHubのリポジトリに**上書きアップロード**します。
   - `.github` フォルダー(自動更新の設定)は**今回は変更なし**です。今のままで使えます。
   - まだリポジトリがない場合は、`requirements.txt` も一緒に上げて、
     GitHubの画面で「Add file → Create new file」を選び、ファイル名に `.github/workflows/update-events.yml` と入力して
     自動更新の設定を作ってください。
2. Settings → Actions → General → Workflow permissions が **Read and write permissions** になっているか確認します。
3. Actions タブ →「Update Eventernote events」→ **Run workflow**(forceはオフのまま)を押します。
4. 1〜2分で緑のチェックが付けば完了です。サイトの下のほうの「イベントデータ」欄に
   「イベンターノートの登録 85件と一致 ✓」と出ます。
5. 以後は毎日自動で更新されます。

## ログの見かた(Actions → 実行 → sync → ログ)
- `2025-07: 2件 (この月の累計2件 / 全体xx件)` … 月ごとに読んだ件数。「カレンダーの○件に足りません」と出たら、その月は読み直されます。
- `集めた件数(重複を除く): 85件 / イベンターノートの表示: 85件` が一致していれば成功です。
- `(参考)…重複して出ていたので、○行を1件にまとめました` … イベンターノート側のページ送りで起きる重複を、取り除いた印です。

## うまくいかないとき
- 赤い×になったら、ログの「エラー:」の行を見てください。「○件足りません」なら、もう一度 **Run workflow** を押すと読み直します
  (読むたびに抜ける場所が変わるので、2回目で揃うことがあります)。
- どうしても一致しないが内容は正しい、というときだけ、「Run workflow」の **force** にチェックを入れると保存できます
  (サイトには「⚠」付きで差が表示されます)。
- Actions側のアクセスが拒否される場合は、自分のPCで `pip install -r requirements.txt` のあと
  `python sync_events.py` を実行し、できた `events.json` をアップロードしてください。

## 注意
- 同期は公開ページの情報だけを読み取ります。非公開情報やログインが必要な情報は取得しません。
- 同梱の `events.json` は、同期が成功するまでの補完データ(85件)です。同期が成功すると置き換わります。
- `events.json` の `url` が空の行が1件あります(2026-04-19 アニメイト回 第一部)。次の同期で自動的に入ります。
